# Vitaltecuida POS Reports

## Descripción

Módulo para generar informes detallados de sesiones POS con desglose completo por ticket.

## Características

- **Informe Detallado por Sesión**: Visualiza todos los tickets de una o varias sesiones POS
- **Desglose por Ticket**: Cada pedido muestra:
  - Número de ticket y referencia
  - Fecha y hora
  - Cajero
  - Cliente
  - Líneas de productos (cantidad, precio, descuentos, impuestos)
  - Métodos de pago utilizados

- **Resúmenes Completos**:
  - Total por formas de pago
  - Total por impuestos (base imponible y cuota)
  - Totales generales

- **Filtros Opcionales**:
  - Por rango de fechas
  - Selección múltiple de sesiones
  - Tipo de informe (detallado o resumen)

## Uso

1. Ir a **Punto de Venta → Sesiones**
2. Seleccionar una o más sesiones
3. Hacer clic en **Acción → Informe Detallado de Sesiones**
4. Configurar filtros opcionales
5. Hacer clic en **Imprimir Informe**

El informe se generará en PDF listo para descargar, imprimir o auditar.
